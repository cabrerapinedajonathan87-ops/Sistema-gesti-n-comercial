Manual de Usuario - Sistema de Gestión Comercial

1. Requisitos del Sistema

  • Python 3.x instalado en el equipo.
  • Ninguna librería externa adicional (utiliza módulos nativos de Python como os, datetime, string, etc.).

2. Cómo Ejecutar el Sistema

  1. Abre tu terminal o consola de comandos en la carpeta raíz del proyecto.
  2. Ejecuta el siguiente comando para iniciar el programa:
    python src/main.py
  3. Guía de Navegación por el Menú Principal
    Al iniciar el sistema, verás el menú principal con 5 opciones numéricas:

Plaintext

 SISTEMA DE GESTIÓN COMERCIAL

=======================================

  1. Gestión de Productos 📦
  2. Registro de Ventas 🛒
  3. Control de Inventarios 🏢
  4. Reportes y Estadísticas 📊
  5. Salir del Sistema ❌
    =======================================
    Módulo 1: Gestión de Productos 📦
    Permite dar de alta nuevos artículos, consultar detalles mediante códigos únicos, actualizar precios o nombres, y desactivar productos que ya no se comercializan sin perder el histórico de ventas pasadas.

Módulo 2: Registro de Ventas 🛒
Te permite ingresar los códigos de los productos que el cliente desea comprar.

Puedes añadir múltiples artículos al carrito de compras virtual.

Para finalizar la venta y facturar, escribe la palabra FIN.

El sistema calcula automáticamente el subtotal, el IVA (12%) y el total a pagar, descontando de inmediato las unidades del inventario y generando un comprobante en pantalla.

Módulo 3: Control de Inventarios 🏢
Consultar Existencias: Muestra un listado rápido de cuánto stock queda de cada producto en bodega.

Registrar Entrada: Permite reabastecer mercancía ingresando el código del producto y la cantidad que entra, guardando un registro en el historial.

Alertas de Stock Mínimo: Revisa automáticamente qué productos están por debajo del límite de seguridad establecido y emite advertencias visuales (🚨).

Historial de Movimientos: Muestra el kárdex detallado de entradas y salidas de la bodega.

Módulo 4: Reportes y Estadísticas 📊
Ofrece un desglose analítico completo del negocio:

Listado general de productos.

Reporte de stock crítico.

Historial completo de ventas y facturas emitidas.

Total de ingresos monetarios recaudados en caja.

Producto líder en ventas (el más vendido).

Valor total del inventario valorizado a precio de venta.

Promedio de facturación por ticket de venta.

Módulo 5: Salir del Sistema ❌
Cierra la aplicación guardando de forma segura y automática todos los cambios recientes en los archivos de texto locales.
