Manual Técnico - Sistema de Gestión Comercial

1. Introducción y Arquitectura del Sistema

El Sistema de Gestión Comercial es una aplicación desarrollada en Python (modo consola) bajo un paradigma modular. Su propósito es automatizar las operaciones comerciales básicas de un micronegocio, controlando el inventario, registrando transacciones de venta con cálculo automático de impuestos y generando reportes estadísticos avanzados.

Estructura de Directorios y Módulos

El proyecto sigue una arquitectura limpia dividida en responsabilidades lógicas:

  • src/main.py: Punto de entrada principal. Controla el flujo de los menús interactivos y la limpieza de pantalla según el sistema operativo.
  • src/estructuras.py: Contiene las estructuras de datos en memoria (listas globales de diccionarios) que almacenan temporalmente los productos, ventas y movimientos.
  • src/productos.py: Lógica de negocio para altas, consultas, modificaciones y desactivación de productos.
  • src/inventario.py: Gestión de entradas de mercancía, existencias y alertas de stock mínimo.
  • src/ventas.py: Procesamiento de carrito de compras, cálculo de subtotal, IVA (12%) y afectación de stock.
  • src/reportes.py: Módulo analítico para cálculo de ingresos, productos más vendidos, valor del inventario y promedios.
  • src/archivos.py: Subsistema de persistencia que serializa y deserializa la información hacia archivos de texto plano (.txt).

2. Persistencia de Datos (Archivos Planos)

El sistema utiliza archivos de texto delimitados para almacenar la información de forma local sin requerir motores de bases de datos externos:

  1. productos.txt: Almacena los datos de cada artículo con el formato de tubería (|):
    codigo|nombre|categoria|precio|cantidad|stock_minimo|activo
  2. ventas.txt: Registra las transacciones procesadas. Los ítems del carrito interno se concatenan mediante punto y coma (;):
    numero_venta|subtotal_general|iva|total|codigo1,cantidad1,subtotal1;codigo2,cantidad2,subtotal2
  3. movimientos.txt: Guarda el kárdex o historial de entradas y salidas de inventario:
    fecha|codigo|tipo|cantidad|descripcion

3. Funciones Clave y Algoritmos Principales

  • Carga y Guardado Automático (archivos.py): Al iniciar la aplicación (__main__), se ejecuta cargar_todo(), el cual lee línea por línea los archivos de texto, limpia espacios en blanco y reconstruye los diccionarios en memoria dentro de estructuras.py. Cada vez que se modifica un producto, se registra una venta o entra mercancía, se ejecuta guardar_todo() para evitar pérdida de datos.
  • Control de Transacciones de Venta (ventas.py): Valida en tiempo real que el código ingresado exista, que el producto esté activo y que la cantidad solicitada no supere el inventario disponible en bodega antes de impactar las existencias.
